# Игра «Угадай число» с таблицей рекордов

## Описание
Интерактивная веб-игра, в которой компьютер загадывает случайное число от 1 до 100, а пользователь пытается его отгадать. После каждой попытки игра даёт подсказки «больше» или «меньше». Результаты сохраняются в таблицу рекордов.

## Функционал
- Генерация случайного числа (1-100)
- Подсказки «больше» / «меньше»
- Подсчёт количества попыток
- Ввод имени игрока
- Таблица рекордов (топ-10, сортировка по попыткам)
- Сохранение рекордов в localStorage
- Кнопка «Новая игра» без перезагрузки страницы
- Адаптивный интерфейс
- Обработка ошибок ввода

**Способ 2. Выполните команды в терминале:
- 'git clone https://github.com/kochurakirr1-png/game-ugadai-chislo.git'
- 'cd game-ugadai-chislo'
- 'start index.html' (windows) или 'open index.html' (macOS)
